# RecordContext - Structured LLM Context

Optional pattern for providing rich, schema-validated context to LLM.

## When to Use

**Skip for simple models.** Just override `mentionable_summary`:

```ruby
class Project
  include Mentionable
  
  def mentionable_summary
    "Project #{name}, status: #{status}, #{tasks.count} tasks"
  end
end
```

**Use RecordContext when:**
- Model has complex nested data
- You want structured types autogenerated
- You need schema validation in development

## Example: WorkspaceContext

See `app/models/contexts/workspace_context.rb`:

```ruby
class WorkspaceContext < RecordContext
  schema do
    description "A workspace where users collaborate"

    string :id, description: "Workspace ID (org_xxx)"
    string :name, description: "Workspace display name"
    string :path, description: "CLICKABLE PATH - use this for markdown links to this workspace"
    string :type,
      description: "Type - personal (single member) or team (multi-member)",
      enum: ['personal', 'team']
    integer :members_count,
      description: "Number of members in the workspace",
      minimum: 0
    string :owner_username, description: "Owner's @username"
  end
  
  def self.from_record(workspace)
    new(
      id: workspace.to_param,
      name: workspace.name,
      path: workspace.mentionable_path,
      type: workspace.personal? ? 'personal' : 'team',
      members_count: workspace.members_count || 0,
      owner_username: workspace.owner.username
    )
  end
end
```

## How It Works

**1. Mentionable#to_llm_context tries to find Context class:**

```ruby
def to_llm_context
  context_class = Mentionables.context_class_for(self.class)

  if context_class
    context_class.from_record(self)
  else
    to_llm_mention  # Fallback if no Context class exists
  end
end
```

**2. ChatStreamJob uses it for @mentioned records:**

```json
{
  "id": "org_xxx",
  "name": "Acme Corp",
  "type": "team",
  "members_count": 5,
  "owner_username": "alice"
}
```

**3. LLM gets clean, structured JSON.**

## Creating a Context

```ruby
# app/models/contexts/project_context.rb
class ProjectContext < RecordContext
  schema do
    description "A project in the workspace"

    string :id, description: "Project ID"
    string :name, description: "Project name"
    string :status, description: "Current status"
    integer :tasks_count, description: "Number of tasks", minimum: 0
  end
  
  def self.from_record(project)
    new(
      id: project.to_param,
      name: project.name,
      status: project.status,
      tasks_count: project.tasks.count
    )
  end
end
```

That's it. Now `@mentions` of projects get structured context.

## Type Generation

RecordContext can generate type definitions (see `RecordContext` docs).

## When NOT to Use

- Simple models with 2-3 fields → just use `mentionable_summary`
- Personal projects → don't over-engineer
- Prototyping → add later if needed

RecordContext is **optional polish**, not required.
